HOW TO PLAY
그림자에 발을, 공에 라켓을.
단식, 3세트 중 2세트 선승. 코트를 교대해도 내 선수는 항상 하단, 상대는 상단이다. 카메라는 돌거나 따라가지 않고 방향키도 화면 기준을 유지한다.

  

   
키보드
방향키화면 기준 이동. 타격 좌우 방향, ↑ 깊게 · ↓ 짧게. 서브 직후 짧은 구간에도 좌우 입력.
X · GB A토스 / 강한 서브 / 가로로 미는 스트로크. 높은 공은 스매시.
Z · GB B약한 서브 / 아래에서 위로 띄우는 로브. 바운드 전이면 약한 발리.
S / A키보드의 첫째 / 둘째 특수기술. 키보드 A는 GB A와 다르다.
Enter / Esc일시정지·계속. 전체 화면에서 Esc는 먼저 닫기.
F / M전체 화면 / 효과음·음악 켜기·끄기.
코드 편집 중에는 경기 키를 가로채지 않는다. Ctrl+Enter로 코드를 실행한다.

   
게임패드
십자키·왼 스틱으로 이동한다. 위치 기준 오른쪽 단추(A 위치)는 X 타격, 아래 단추(B 위치)는 Z 로브다. L·R 어깨 단추로 특수기술을 쓴다. Start는 메뉴다.
연결된 패드 없음
브라우저 표준 매핑 패드를 대상으로 한다. 실제 패드의 호환성은 기기·브라우저에 따라 다르다.
마우스와 모바일
메뉴·코드 편집만 마우스로 할 수 있다. 코트를 누르거나 드래그해도 선수는 움직이거나 공을 치지 않는다. 터치 조작판은 없다. 외부 입력 장치 없는 휴대폰에서는 경기 조작이 불가능하다.

   
서브와 리턴
먼저 좌우로 서브 위치를 고른다. X로 약 1초 동안 공을 띄우고 X 또는 Z로 친다. 너무 높을 때 누르면 닿는 높이까지 준비한다. 높은 타점은 깊게, 낮은 타점은 짧게 간다. 타격 직후 0.12초 안의 좌우 입력은 누른 시간·스틱 기울기에 따라 착지를 더 옮긴다. 그 뒤에는 공을 조향하지 않는다. 이 입력 여유는 동현테에서 넓힌 값이다.
빈 토스는 폴트 없이 다시 한다. 서비스 박스는 대각선이며 두 번 폴트면 상대 포인트, 네트를 스친 유효 서브는 렛이다. 그림자는 바닥 위치, 공은 높이다. 서브는 한 번 바운드한 뒤 받는다. X는 가로 스트로크·강한 발리·높은 공의 스매시, Z는 띄우는 로브·약한 발리다.

   
점수와 코트 교대
0 → 15 → 30 → 40. 듀스에서는 두 점 차로 게임을 딴다. 6게임 이상, 두 게임 차면 세트. 6 대 6에서는 7점 타이브레이크로 두 점 차를 낸다.
게임마다 서브를 바꾸고 홀수 게임 뒤에는 코트를 바꾼다. 타이브레이크는 첫 1점 뒤부터 두 점마다 서브 교대, 6점마다 코트 교대다. 2세트를 먼저 따면 승리한다.

  

 

 
REFERENCE & IMPLEMENTATION
원작에서 배운 것.
동현테에서 더한 것.
업로드한 32 KB TENNIS 롬을 에뮬레이터에서 실행해 코트·선수 크기·토스·공과 그림자를 관찰했다. 롬의 기계어를 완전히 역분석한 것은 아니며, 물리 상수와 타격 판정이 원작과 수치적으로 일치한다고 주장하지 않는다.

  
원작에 맞춘 조작
A 일반 스트로크·강한 발리, B 로브·약한 발리, 머리 위의 공은 자동 스매시, 토스 후 타격, 타격 순간 방향키의 방향·깊이 조절을 따른다. 단순한 탑스핀/슬라이스 분류로 바꾸지 않았다.
Nintendo Tennis 원작 설명서 ↗
독립 물리 구현
120 Hz 고정 틱, 바닥 X/Y와 높이 Z, 중력과 포물선, 네트 통과 높이, 타점 높이·거리, 바운드 순간의 인·아웃을 계산한다. 원작처럼 보이는 고정 시점이지만 내부 좌표·수치와 화면 투영은 새로 작성했다.
원작과 동작을 더 정밀하게 맞추는 과정은 계속된다. 현재 판은 플레이 가능한 첫 구현이다.
새로운 규칙과 그림
일곱 선수의 능력, 열네 기술, 세 난이도와 네 코트는 동현테의 규칙이다. 반발계수·감속률은 게임 조절값이지 실제 대회의 측정치나 원작 롬에서 추출한 수치가 아니다.
포동이의 흰 귀·주둥이, 동현파 원본의 슈슈, 꽥꽥의 부리, 잔 다르크의 투구·깃발을 작은 도트로 단순화했다. 뭉치·뚱띠·또치는 기존 지휘관 이름·색을 잇고 테니스용 모습을 새로 그렸다.
이용과 권리
원작 롬·도트·음악은 배포물에 포함하지 않는다. Nintendo Tennis 및 언급한 원작의 권리는 각 권리자에게 있다. 비공식 팬 실험이며 승인·후원 관계는 없다.
코드 MIT, 글꼴 OFL. 동현랭 실행기는 시리즈의 원본을 사용한다. 효과음과 짧은 음악은 Web Audio로 새로 만든다. 벽 충돌 기술에는 비사실적인 붉은 도트 연출이 있다.
