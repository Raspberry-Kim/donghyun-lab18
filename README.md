# 동현테 v0.13

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24133576.svg)](https://doi.org/10.5281/zenodo.24133576)

동현랭 코드로 선수·난이도·경기장을 정하는 1인용 단식 테니스다. Game Boy Tennis의 조작을 참고한 독립 구현이며, 카메라는 움직이지 않는다.

v0.13에서는 선수 둘이 더 왔다. **이삐**는 꽥꽥만 한 키의 단발 어린 소녀로, 얼굴은 슈슈를 닮았다(공격 70 · 수비 90 · 이동 100). S **양재천범람**을 켜면 내가 친 공과 함께 물결이 네트를 넘어 상대를 덮치고, 젖은 상대의 이동은 90% 느려진다. A **브롬톤앞바퀴**는 닿지 않는 공에 타격 키를 누르면 앞바퀴를 타고 0.2초 동안 굴러가 친다. 동현의 샤아자쿠보다 조금 느리고, 다섯 번에 한 번꼴로 공 옆으로 미끄러져 놓친다. **빽빽**은 슈슈와 거의 같은 모습에 똥머리와 연보라 원피스만 다르다(공격 90 · 수비 100 · 이동 110). S **오마이갓**을 켜면 내가 친 공이 하트 다섯 갈래로 갈라지는데 진짜는 무작위 하나뿐이다. 상대가 우연히 진짜를 고르면 랠리가 이어진다. A **백미취사완료**를 켜면 내가 공을 칠 때부터 상대가 취한 듯 비틀거리며 네트 쪽으로 걸어온다. 선수는 아홉, 기술은 열여덟, 예제는 81개가 됐다.

v0.12에서는 ‘수학적 원리’를 처음부터 다시 맞춰 봤다. 스매시의 수평 속도 배수를 바운드 뒤(×0.74)와 바운드 전(×0.80×0.74≈0.59)으로 나눠 바로 적었고, 긴 식은 좁은 화면에서 잘리지 않고 그 자리에서 줄이 바뀐다. 경기 규칙과 조작은 그대로다.

v0.11에서는 포동이 얼굴을 시리즈 머리글 아이콘처럼 둥글게 다듬고 귀를 흰색으로 맞췄다. 까만 눈과 코, 작은 입을 넣었고 키는 꽥꽥만큼 작다. 몸과 동작은 그대로이며, 쓰러진 자세의 머리에 생기던 줄무늬도 고쳤다.

관중석에서는 작은 웅성거림이 들리고, 득점에는 박수, 긴 랠리와 스매시에는 환호가 이어진다. 라켓이 부러지거나 게임을 내주면 항의성 소음도 들린다. 모두 녹음 없이 합성한 소리다. 머리글 소리 단추나 M으로 함께 끌 수 있고, 메뉴를 열거나 다른 탭으로 이동하면 관객 소리도 멈춘다.

v0.10에서는 상대가 경기마다 바뀐다. 내 선수를 뺀 여섯 명 가운데 무작위로 정해지므로 같은 선수끼리는 만나지 않는다. 동현의 뒤통수는 검은 점을 줄인 부드러운 회색으로 바꿨다. 화면을 두 배 해상도로 그려 슈슈를 동현파 원본 도트 그대로(1:1) 보여 주고, 다른 여섯 선수는 크기와 모양을 그대로 둔 채 도트 사이 틈만 없앴다.

v0.09에서 내 선수는 출전 전 시작 카드에서만 앞 얼굴을 보이고, 출전한 뒤에는 뒤통수를 보인다. 상대 선수는 계속 앞을 본다. 동현은 머리 위 꽁지머리를 없애고 흰머리와 검은머리가 섞인 색으로 바꿨다.

v0.08은 머리 중심의 둥근 캐릭터를 그렸다. 동현은 흰 머리 남성, 뭉치와 꽥꽥은 단발 여성(꽥꽥은 조금 작은 키), 뚱띠는 넓고 건장한 인상, 또치는 귀엽고 가느다란 인상이다. 포동이의 흰 귀·주둥이를 키웠고 슈슈의 원본 디자인·몸체·팔다리·라켓과 고정 코트는 보존했다. 상대 슈슈는 대기와 후진에서도 앞을 본다.

v0.07에서는 메뉴에 **왜 ‘Open’일까?**와 **수학적 원리**를 더했다. 앞의 것은 아마추어의 어원, 프로의 메이저 배제, 1968년 오픈 에라와 상금, 골프 디 오픈과의 비교를 출처와 함께 싣는다. 뒤의 것은 120 Hz 고정 틱, 가상 Z축 포물선과 그림자, 목표점·비행시간으로 푸는 타격 속도, 네트·바운드 사건 시각, 코트별 반발, 서브 타점 품질, 타격 상태 머신, 동현AI™ 예측, 고정 화면 투영을 엔진 코드의 식 그대로 설명한다. 경기 규칙·물리·저장 형식은 바꾸지 않았다.

v0.06에서는 코트를 세로로 조금 길게 하고 선수의 몸·머리 폭을 약 10% 줄였다. 공은 상대 코트로 갈수록 작아지고 바닥에 닿을 때도 더 작아진다. 높이 올라가면 커지는 표현은 그대로다. 전체 화면 단추는 코트·키 안내와 간격을 두었고 좁은 전체 화면의 코트 비율을 바로잡았다. 카메라는 고정되어 있고 타격·점수·특수기술·저장 규칙은 v0.05와 같다.

경기 중 Enter 메뉴에서 브라우저 칸 3개나 `.dhsave` 파일로 저장하고 불러온다. 예제 81개는 통상(01–36) · 프로(37–72) · 초보(73–81) 순서다. 지속형 기술은 랠리가 끝날 때까지 남고, 필승형 네 기술은 성공할 때까지 다음 랠리에도 준비가 남는다. 액슬로즈는 라켓을 두 번 내리쳐 부수고 지금 게임만 내준다. 기술 칸에는 준비됨·발동 중·유지 조건이 표시된다.

v0.04에서는 페이지의 색과 큰 틀을 동현큐·동현심 등 시리즈의 다른 실험실과 맞추었다. 종이색 바탕과 노란 강조, 포동이 머리글, 소개와 입력 표식, 노란 밑줄 탭, “처음이라면?” 상자, A 코트 · B 동현랭 출전 코드의 두 칸 배치, 구문 강조 편집기가 같은 모양이다. 코트 그림과 경기 화면 안의 점수판·기술 띠, 선수·공·물리 규칙은 v0.03과 같다.

v0.03에서는 특수기술을 쓸 때 코트 위에 선수·기술명·준비/발동 표지가 잠깐 뜨고, 선수 곁에 기술마다 다른 작은 상징과 입자가 퍼진다. 예제는 24개로 늘었고, 모든 이름을 번호·선수·난이도·코트 순서로 맞추었다. 예제와 직접 고친 코드 모두 난이도와 코트의 차이를 함께 설명한다. 공·선수·코트 그림과 경기 물리는 v0.02와 같다.

## 시작과 조작

데스크톱을 권장한다. 경기에서는 키보드와 표준 매핑 게임패드를 사용하고, 마우스·터치 이동이나 타격은 제공하지 않는다. 휴대폰에서 경기하려면 별도의 키보드를 연결하자.

| 키 | 동작 |
|---|---|
| 방향키 | 이동, 타격 방향·깊이 |
| X | 토스, 강한 서브, 스트로크 |
| Z | 약한 서브, 로브·약한 발리 |
| S / A | 첫째 / 둘째 기술 |
| Enter | 출전, 메뉴(계속 · 저장 · 불러오기 · 포기) |
| F / Esc | 전체 화면 / 닫기 |
| M | 소리 전환 |
| Ctrl+Enter | 코드로 새 경기 시작, 진행 중이면 확인 |

메뉴에서는 ↑↓로 고르고 Enter·X로 선택, Z·Esc로 뒤로 간다. 게임패드는 십자키·왼 스틱 위아래, 오른쪽 단추·Start 선택, 아래 단추 뒤로다.

GB A는 X, GB B는 Z다. X는 가로로 미는 스트로크, Z는 아래에서 위로 띄우는 로브로 자세·궤적을 구별한다. 라켓 타원의 긴 축은 손잡이와 이어지고, 회전 중 면 너비도 달라진다.

서브는 좌우 출발 위치를 고르고 X로 토스한 뒤 X/Z로 친다. 높은 공 입력은 준비해 두었다가 닿는 높이에서 친다. 출발 위치·타점 높이·타격 직후 0.12초의 방향 입력이 함께 착지를 결정한다. 짧게/길게 누르는 시간과 스틱 크기를 반영하되 그 뒤 공 조향은 없다. 이 입력 구간은 원작 수치의 복제가 아니라 동현테의 여유 설정이다. 공은 높이에 따라 커지고 토스에는 ‘부웅’ 상승음이 난다.

코트 교대의 경기 좌표는 유지하되 화면 좌표를 변환해 내 선수는 항상 하단에 둔다. 카메라는 움직이지 않고 방향키는 화면 기준으로 작동한다.

코드는 선수 1–9, 난이도 1–3, 경기장 1–4를 차례로 출력한다. 선수 번호는 동현·뭉치·뚱띠·또치·포동이·꽥꽥·슈슈·이삐·빽빽 순이다. 예제는 통상 36개 → 프로 36개 → 초보 9개 순서이고, 묶음 안에서는 선수 순, 같은 선수면 코트 순이다. 통상·프로에서는 아홉 선수 모두 네 코트를 선택하며 초보 예제는 모두 윔블던이다. 01·37·73으로 동현·윔블던의 난이도를 비교하고, 각 선수의 통상·프로 예제 네 개로 코트를 비교하자. 선수 카드의 ‘코드 불러오기’는 그 선수의 초보·윔블던 예제를 연다. 직접 코드를 쓰면 초보의 다른 코트도 선택할 수 있다.

## 저장과 불러오기

경기 중 Enter 메뉴의 ‘저장’에서 브라우저 칸 1–3이나 `.dhsave` 파일에 지금 경기를 담는다. 점수·서브 순서·에너지, 날아가던 공, 준비한 기술, 난수 상태까지 들어 있어 불러오면 같은 입력에 같은 결과가 이어진다. 불러오기는 메뉴와 코트 탭 B 칸 아래에 있고, 불러온 경기는 멈춘 채로 열린다. 출전 코드 칸도 불러온 경기의 설정으로 바뀐다.

브라우저 칸은 그 기기의 그 브라우저에만 남는다. 사이트 데이터를 지우면 사라지므로 오래 둘 경기는 파일로 내려받자. 끝난 경기는 저장하지 않는다. 저장 형식이 아니거나 값이 범위를 벗어난 파일은 이유를 알리고 거절하며, 하던 경기는 그대로 둔다. 저장 파일의 글자는 화면에 글자로만 표시한다.

## 구현

특수기술이 받아들여지면 코트 상단에 선수·기술명과 준비/발동 상태가 약 1.6초 나타나고, 코트 가장자리에 기술 색 테두리가 두 번 맥동한다. 불꽃·혜성·시계·음표·발바닥·하트·표적 등 작은 상징과 입자가 효과를 알린다. 다음 타격을 기다리는 기술은 먼저 ‘준비’, 실제 사용 때 ‘발동’으로 구별한다. 실패한 입력에는 성공 연출이 없고 기존 상태 줄에 이유가 나온다. 카메라는 흔들리지 않으며 화면 전체를 덮는 섬광도 없다. 메뉴를 열면 연출도 멈춘다. 기기의 동작 줄이기 설정에서는 상징과 표지만 정적으로 표시한다.

기술이 걸려 있는 동안에는 코트에도 표시가 남는다. 준비한 기술은 발밑 고리, 울트라롱팔은 남은 횟수 점과 공까지 뻗는 팔, 리만가설은 예상 궤적과 십자 표식, 와루이지와나는 공 둘레 시계 고리, 컴온스펜서는 음표, 아잉뿌잉은 하트와 남은 시간 칸이다. 양재천범람은 공을 따라가는 물마루와 물에 잠긴 상대 코트, 브롬톤앞바퀴는 발밑 바퀴와 굴러간 자국, 오마이갓은 나란히 날아가는 하트 다섯 개(그림자는 진짜 공에만 있다), 백미취사완료는 상대 머리 위를 도는 고리와 비틀거리는 걸음이다. 불꽃·바람·드롭·사라지는 공은 공 자체에 꼬리와 깜박임이 붙는다. 코트 아래 기술 칸에는 ‘준비됨 · 다음 리턴’, ‘발동 중 · 남은 2번’처럼 상태가 적히고, 풀릴 때는 안내 줄에 알린다.

액슬로즈는 약 2.8초 동안 라켓을 들어 한 번 내리치고, 다시 들어 두 번째로 내리쳐 부순다. 라켓 머리가 날아가 코트에 남고 파편과 균열이 보인다. 그 뒤 지금 게임이 상대에게 넘어가고 다음 게임으로 이어진다. 타이브레이크에서는 타이브레이크가 곧 한 게임이므로 그 세트를 내준다. 내준 게임으로 세트나 경기가 끝나면 평소 규칙대로 끝난다.

예제 제목은 모두 ‘번호 · 선수 · 난이도 · 코트’ 순서다. 예제 선택 칸 아래 설명에서 속도 배율, 상대 재판단 간격과 바운드 전 좌우 목표 오차, 수직 반발과 수평 속도 유지율을 확인하자. 수직 반발 계수는 바운드 직후 속도의 비율이지 높이의 비율은 아니다. 이 수치는 원작에서 추출한 값이 아닌 동현테의 자체 설정이다.

- **선수**: 동현·뭉치·뚱띠·또치·포동이·꽥꽥·슈슈·이삐·빽빽, 선수별 능력치와 18개 기술.
- **경기장**: 윔블던·호주·US·프랑스. 색상·반발·바운드 뒤 속도 유지율을 구분.
- **기술 에너지**: 시작·최대 6칸, 일반 기술 1칸·즉시 승리 3칸. 포인트 종료마다 +2, 성공한 리턴 2회마다 +1. 두 기술 동시 준비, 중복 입력 무과금. 포인트 사이에도 지속형/필승형을 미리 준비할 수 있다.
- **기술 수명**: 샤아자쿠·사세보후우샤·와루이지와나·컴온스펜서·멍멍·아잉뿌잉·울트라롱팔·리만가설·양재천범람·브롬톤앞바퀴·오마이갓·백미취사완료는 랠리 종료까지 유지한다. 이삐·빽빽의 네 기술은 서브도 타격으로 세고, 폴트·렛에서는 그대로 남는다. 샤아아즈나블·구마몬기쥬츠·비밀이야·알려고하지마는 유효한 착지로 성공해야 소모된다. 아웃·더블 폴트·사용 못 한 포인트 뒤에도 다음 랠리로 이월한다. 오겡끼데스까·액슬로즈는 즉시 결과 기술이다. 상대 AI는 기술을 쓰지 않는다.
- **저장 호환**: 이전 v1 저장도 읽는다. 이전 횟수·초 단위의 긴 팔·쓰러짐과 준비된 혜성/바람 효과는 불러올 때 새 랠리 지속 규칙으로 바꾼다. 파일의 점수·코트·난수·공 좌표는 보존한다.
- **기본 경기**: XYZ 포물선, 그림자, 높이·거리·타이밍 타격, 서브 폴트·렛, 네트·인·아웃·두 번 바운드, 듀스·어드밴티지·타이브레이크·2세트 선승.
- **화면**: 고정 시점, 단순한 절차적 도트, 앞·뒷모습, 잔 다르크 심판, 밝은/어두운 UI.
- **상대**: 내 선수를 뺀 여덟 명 가운데 경기마다 무작위. 같은 선수끼리는 만나지 않는다. 슈슈는 동현파 원본의 양쪽 둥근 머리·리본·분홍 원피스·빨간 운동화 도트를 1:1로 쓴다. 동현AI™는 일반 타격만 사용한다.

## 원작과의 관계

1989 GB 테니스를 실행하여 코트·선수 크기·토스·공과 그림자를 관찰했다. 기계어를 역분석한 것이 아니며, 물리 상수와 타격 판정이 원작과 수치적으로 일치하지 않는다. 이 구현을 정확한 복제라고 부르지 않는다.

두 단계 서브, A 스트로크·강한 발리, B 로브·약한 발리, 높은 공의 스매시와 방향 조절은 [Nintendo Tennis 설명서](https://www.thegameisafootarcade.com/wp-content/uploads/2017/04/Tennis-Game-Manual.pdf)를 참고했다. 원작에서 관찰한 화면 이동은 재현하지 않았다. 동현테는 고정 시점으로 진행한다.

네 코트의 계수는 자체 조절값이다. 실제 대회 측정치나 롬에서 추출한 상수가 아니며, 세 난이도와 특수기술도 동현테의 추가 규칙이다.

## 개발

```sh
node qa/core.cjs
node qa/skill-rules.cjs
node qa/rally-skills.cjs
node qa/skill-cues.cjs
node qa/motion.cjs
node qa/round.cjs
node qa/serve-timing.cjs
node qa/racket-input.cjs
node qa/new-skills.cjs
node qa/bot.cjs
node build.cjs
# 브라우저 검사: dist를 3018번 포트로 띄운 뒤
node qa/examples-ui.mjs
node qa/save-ui.mjs
node qa/pad-menu.mjs
node qa/layout-ui.mjs
```

`src/engine.js`는 화면과 독립적인 120 Hz 엔진이다. `render.js`는 도트·코트, `app.js`는 동현랭·입력·메뉴·소리를 담당한다. `build.cjs`는 원본 실행기와 글꼴을 포함한 단일 HTML을 `dist`에 만든다.

웹 배포 대상은 `dist`뿐이다. 롬·에뮬레이터 상태·원작 캡처·비공개 분석 자료는 저장소·릴리스·Zenodo 보관본에 포함하지 않는다.

## 시리즈 연결

[동현랭](https://raspberry-kim.github.io/donghyun-lang/)과 열여덟 실험실을 상단 메뉴로 오간다. [동현테](https://raspberry-kim.github.io/donghyun-lab18/)는 고정 시점의 1인용 단식 테니스다. 데스크톱 메뉴는 동현랭이 두 줄 높이, 나머지는 9열×2줄이다. 모바일은 두 열이며 홀수 개일 때 동현랭만 두 칸 너비를 쓴다.
